## О чём это

Ω⁴-UNIFIED — попытка построить физическую модель, в которой **топология многообразия Калаби-Яу порождает структуру физики**:
    от масс элементарных частиц до космологических параметров и квантовой гравитации.

Всё начинается с **Тянь-Яу / Z₃** — конкретного многообразия Калаби-Яу с числами Ходжа:

```
h¹¹ = 6,  h²¹ = 9,  χ_Hodge = −6,  N_gen = 3
```

Из этих чисел через мастер-полином `n(k) = (103k⁴ − 370k³ + 101k² + 478k)/12` выводятся:
- **β-функции SU(26)** — топологические инварианты, а не спектральные;
- **массы частиц** — через ε_FN = 0.317081645… (параметр Фроггатт-Нильсена);
- **космологические параметры** — n_s, r, H_0, Ω_DM, Λ;
- **квантовая гравитация** — M_Pl, G, Λ через FRG.

---

## ⚠️ Честный дисклеймер

**Это рабочая гипотеза, а не доказанная теория.**

- **PROVEN не достигнут.** Связь N_eff = 7 — наблюдаемая закономерность, а не строгий вывод.
- **Модель — EFT, не струнная теория.** У неё есть 26D, SU(26) и компактификация, но **нет** действия Полякова,
вершинных операторов и спектра замкнутых струн.
- **SU(26) — феноменологический вход**, а не следствие первых принципов.
- **5 открытых проблем**: объединение констант, M_Z, sin²θ_W, α_s(M_Z), SUSY из гравитации.

Мы честно указываем это здесь, чтобы не создавать ложных ожиданий.
Детали — в разделе «Ограничения» и в файле `LIMITATIONS.md`.

## Как запустить

### 1. Установка зависимостей

```bash
pip install numpy scipy mpmath
```

`mpmath` — обязателен: без него `ε_FN` не посчитается с нужной точностью.

### 2. Полный прогон

```bash
python main_unified.py
```

Это запустит **всё**:
1. Базовую модель (171 проверка, `omega4_results.json`)
2. Доп-проект (9 файлов, `research_results.json`)
3. FRG-диагностику (граница 7/8)
4. Объединённый JSON (`unified_results.json`)
5. Автогеном (`constants_genome_omega4.py`, 629 констант)

### 3. Отдельные части

```bash
# Только базовая модель
python main.py

# Только доп-проект
python main_research.py

# Только FRG-граница
python check_frg_limit.py

# Только ядро
python core.py

# Только скан атласа
python atlas_scan.py

```

### 4. Аргументы `main_unified.py`

## Ограничения

Подробности — в `LIMITATIONS.md`. Кратко:

1. **Модель — EFT, не струнная теория.** Нет действия Полякова, вершинных операторов, спектра замкнутых струн.
                                          Статус: `STRUCTURAL_ARGUMENT`.
2. **PROVEN не достигнут.** Связь N_eff = 7 — наблюдаемая закономерность, не вывод.
3. **SU(26) — феноменологический вход.** Обоснована через n(1) = 26, χ = 26·24 − 8, компактификацию 26 = 4 + 6 + 16.
                                          Но не выведена из первых принципов.
4. **5 открытых проблем:**
   - Объединение констант (разброс α_i⁻¹ = 22.32)
   - M_Z (откл. 0.009%)
   - sin²θ_W (откл. 0.046%)
   - α_s(M_Z) (откл. 0.031%)
   - SUSY из гравитации (гипотеза)
5. **Спектр SU(26) отвергнут** для RGE — топология работает напрямую.
